# services

Esta carpeta contiene servicios para interactuar con APIs, manejar autenticación y lógica de negocio que no pertenece a los componentes.

- **api.js**: Configuración y funciones para peticiones HTTP.
- **authService.js**: Funciones de autenticación (login, registro, manejo de tokens).

Los servicios deben ser independientes y reutilizables en diferentes partes de la aplicación.
