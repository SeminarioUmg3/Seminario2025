# components

Esta carpeta contiene todos los componentes reutilizables de la interfaz de usuario. Los componentes pueden ser UI genéricos, específicos de funcionalidad (como mapas, formularios de autenticación, etc.) y se organizan en subcarpetas según su tipo o propósito.

- **ui/**: Componentes de interfaz genéricos (botones, inputs, etc).
- **MapLeaflet/**: Componentes relacionados con mapas interactivos.
- **Auth/**: Componentes para autenticación (LoginForm, PrivateRoute, etc).

Cada componente debe tener su propio archivo de estilos y documentación breve en comentarios.
