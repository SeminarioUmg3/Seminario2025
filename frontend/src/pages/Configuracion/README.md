# Pantalla de Configuración

Incluye la gestión de usuarios y roles en pestañas. Se accede desde el panel de configuración del sidebar.

- `Configuracion.jsx`: Componente principal con tabs para Usuarios y Roles.
- `Configuracion.module.css`: Estilos.

## Integración

- Agregar la ruta `/configuracion` en el sistema de rutas.
- En el sidebar, el botón de configuración debe navegar a `/configuracion`.
