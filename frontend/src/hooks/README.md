# hooks

Esta carpeta contiene hooks personalizados de React para manejar lógica reutilizable, peticiones HTTP, autenticación, etc.

- **useAuth.js**: Maneja el estado de autenticación del usuario.
- **useFetch.js**: Realiza peticiones HTTP y gestiona estados de carga y error.

Cada hook debe estar documentado con comentarios sobre su uso y parámetros.
